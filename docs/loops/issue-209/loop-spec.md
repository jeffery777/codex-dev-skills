# Issue #209 — Memory M1 Thin Local Opt-In Pilot

## Objective

Qualify a manual, local/manual/CI-only façade over the existing M1 SQLite/FTS5
reference adapter. It is default-off and advisory-only: repository, Git,
verification, review, and accepted platform state remain the only authority.

## Scope and DoD

- A strict `memory-m1-local-pilot/v1` envelope classifies only verified fact,
  decision, constraint, or evidence-reference labels, bound in the canonical
  `dev.jeffery.memory-pilot/profile` record extension.
- Remember accepts only an existing V2b `durable-lesson` that has already
  completed V2b eligibility and exact M0 operation authority; recall uses
  structured tokens and the existing M1 query then V2b retrieval decision.
- Invalidate is an explicit logical transition; no purge, migration, repair,
  automatic recall/write, lifecycle hook, daemon, provider, or network exists.
- Synthetic-only criteria are pre-registered. Passing means
  `synthetic-pilot-qualified-awaiting-human-decision`, never activation or
  real-world efficacy.

Recall returns only a minimal adopted-context projection (digest, class,
content, and source references) after V2b has evaluated the complete bounded
M1 result. The synthetic task compares the same repository-authoritative
answer with memory off and with that exact projection supplied as advisory
context; context reduction compares a full canonical record with the actual
projection delivered to the task.

The CLI has explicit `remember`, `recall`, and `invalidate` routes with one
strict JSON bundle and explicit state/repository roots. The default `off` route
does not import the adapter or touch the filesystem. Invalidate carries no
profile-class claim and is bounded solely by its exact M0 target authority.

## Release Classification

This adds an installed public CLI/library capability, so pre-1.0 policy selects
the `0.23.0` minor candidate. Tagging and publication remain human gates.
