## Definition Of Done

- Regression cases cover routine review, exceptional preference and fallback,
  safety minima, legacy behavior, and route/digest validation.
- Refactored entry points retain explicit, installed reference paths to optional
  contracts; no safety rule is removed merely to satisfy a line-count target.
- Installed examples work without a target repository `scripts/project-python`.
- Deprecated invocation metadata reaches both filesystem and plugin installs.
- Source/package parity, relevant contract tests and the offline suite pass.
- Code, documentation and security-sensitive boundaries receive independent
  review; every finding has a disposition against the final local diff.
- Static byte/line measurements are labeled separately from actual model usage.
- Remaining model-quality and cost claims have bounded follow-ups, not inferred
  success from synthetic routing fixtures or model-family names.
- Release metadata agrees on 0.24.0; historical notes remain unchanged and
  active guidance remains true after publication. GitHub publication is
  established by annotated-tag and non-draft/non-prerelease Release readback.
