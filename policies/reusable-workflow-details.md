## Decision And Stop Conditions

Read Core authorization/stops and [human gates](human-gate-policy.md).
After failed acceptance, use model-selection-policy.md's 返工分類、升級與續行 and
[context continuity](context-continuity-policy.md). Two unfinished review/fix rounds
trigger reassessment, not automatic task creation or a lower quality threshold.
Classify environment/data/permission failures separately from reasoning failures.

For this repository's selected GitHub profile, the order remains: content review
and required CI → authorized receipt publication/readback → dedicated App
verification → final live merge readback. The receipt's App verdict cannot be its
own publication prerequisite; receipt publication does not authorize merge or
change runtime automatic-approval rules. Other projects select their own overlay.
A skill-caused stop cites the actual SKILL.md clause and checks existing authority;
tool denial is classified and never bypassed or reported as completion.

## Runtime Differences

CLI and Desktop use only their currently documented capabilities and compatible
fallback. Thread/session/worktree/schedule operations need their own authority,
current schema and readback under
[native capabilities (source/plugin)](../docs/native-runtime-capabilities.md);
filesystem installs read
`${CODEX_TEMPLATES_DIR:-$HOME/.codex/templates}/docs/native-runtime-capabilities.md`.
They do not replace repository artifacts or authorize lifecycle operations.
Missing delegation uses one writer; missing session APIs uses manual checkpoints.
Never borrow another surface's qualification.

## Review And Merge

Read full Core review/security and exact-head when triggered, plus the applicable
code-review/docs-review/deep review and formal gate skills. Preserve findings and
all dispositions, sufficient independent reviewers, proportional fix review and
new-head complete range review. [Review artifact](review-artifact-policy.md),
[security escalation](security-review-escalation-policy.md) and the selected
[GitHub profile](github-exact-head-enforcement-profile.md) remain Codex overlays.
Review/gate evidence grants no external-write authority.
